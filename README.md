## Featured Project

### SkillSwap Campus Connect

**Full-Stack Web Application | Solo Project**

A campus-based skill-sharing platform that helps students discover skills, connect with peers, and exchange knowledge.

**Tech Stack:** Java, Spring Boot, Spring Security, JWT, HTML5, CSS3, JavaScript, MySQL, REST APIs, JDBC, Maven, Git, GitHub.

**Key Features & Implementation**

- Developed a platform where students can discover peers, share skills, and send skill-exchange requests.
- Built backend functionality using Java and Spring Boot with a layered architecture consisting of controllers, services, DAO classes, and entities.
- Implemented authentication and authorization using Spring Security and JWT-based authentication.
- Developed interactive pages for user registration, login, profile management, student discovery, and skill-exchange requests.
- Integrated MySQL for database management and data persistence.
- Designed REST APIs to support communication between the frontend and backend.

**[View SkillSwap Campus Connect Repository](https://github.com/Nidhi194/SkillSwap-CampusConnect)**
